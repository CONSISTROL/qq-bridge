12安全拦截通知

拨动即写入 config.json 并立即生效。
开启：回复被安全拦截时会在群里提示；关闭：直接沉默，只在日志/活动记录里留下记录。

12b控制台访问令牌

用于打开本控制台 / 调用管理 API 的令牌。可手动输入新令牌保存，或留空生成随机令牌。修改后当前页面会自动使用新令牌。
用令牌成功打开一次后，桥接会给这个浏览器记一个 HttpOnly Cookie（30 天）：之后刷新、重新打开、直接输网址都不再要求输入令牌。想取消记住就点「忘记本机令牌」。
